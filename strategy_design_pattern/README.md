# 🧩 Strategy Design Pattern

This directory demonstrates the **Strategy Design Pattern** using a simple vehicle-driving example.

We provide two implementations:

1. [`with_strategy_design_patterns`](./with_strategy_design_patterns) – Refactored version using the **Strategy Pattern**.
2. [`without_strategy_design_patterns`](./without_strategy_design_patterns) – Original version with **code duplication** due to inheritance.

## 📚 What You’ll Learn

- The problem with duplicated behavior in subclass hierarchies.
- How the Strategy Pattern solves this using composition and delegation.
- Cleaner, extensible, and maintainable design.

Explore both folders to understand the transformation!
